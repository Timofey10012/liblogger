# liblogger


Библиотека логирования на C++17 с поддержкой записи сообщений в файл и отправки сообщений по TCP-сокету.


Проект выполнен в рамках учебного задания.


## Возможности


Библиотека предоставляет два логгера:


- `FileLogger` — запись сообщений в файл;
- `SocketLogger` — отправка сообщений на TCP-сервер.


Для сообщений поддерживаются три уровня важности:


- `Info`
- `Warning`
- `Error`


Логгер игнорирует сообщения, уровень которых ниже установленного уровня логирования.


Библиотека является потокобезопасной: доступ к общим ресурсам защищён с помощью `std::mutex`.


## Требования


- C++17
- GCC
- CMake
- Linux (Ubuntu/Debian)


Сторонние библиотеки не используются.


## Сборка

Создать директорию для сборки:

``` 
cmake -S . -B build
```

Собрать проект:

``` 
cmake --build build
```

В результате будут собраны библиотека и тестовое приложение.

## Запуск приложения

Приложение принимает два аргумента:

``` 
./example_app <log_file> <default_log_level>
```

Например:

``` 
./build/example_app app.log info
```

После запуска приложение запрашивает сообщение:

```
Message: Hello World
Level (info/warning/error, Enter for default):
```

Если уровень не указан, используется уровень по умолчанию, переданный при запуске программы.

Также можно указать уровень непосредственно для сообщения:

```
Message: Something went wrong
Level (info/warning/error, Enter for default): error
```

## FileLogger

Пример использования:

```
FileLogger logger("app.log", LogLevel::Info);


logger.log(LogLevel::Info, "Application started");
logger.log(LogLevel::Warning, "Something may be wrong");
logger.log(LogLevel::Error, "Something went wrong");
```

Сообщения записываются в указанный файл.

### Изменение уровня логирования

Уровень логирования можно изменить во время работы:

```
FileLogger logger("app.log", LogLevel::Warning);

logger.log(LogLevel::Info, "This message will be ignored");

logger.setLogLevel(LogLevel::Info);

logger.log(LogLevel::Info, "This message will be written");
```

## SocketLogger

SocketLogger подключается к TCP-серверу по указанному IP-адресу и порту:

```
SocketLogger logger("127.0.0.1", 9000, LogLevel::Info);


logger.log(LogLevel::Error, "Connection failed");
```

Для передачи данных используется TCP-соединение.

## Тестирование

Для запуска тестов используется CTest.

Сначала собрать проект:

``` 
cmake --build build
```

Затем:

``` 
ctest --test-dir build
```

### Тесты проверяют основные возможности библиотеки:

- запись сообщения в файл;
- фильтрацию сообщений по уровню важности;
- изменение уровня логирования;
- обработку ошибки открытия файла;
- отправку сообщения через SocketLogger.

## Сборка статической и динамической библиотек


### Проект содержит две цели сборки библиотеки:

- `liblogger_static` — статическая библиотека;
- `liblogger_shared` — динамическая библиотека.

Тестовое приложение в текущей конфигурации использует статическую версию библиотеки.

## Обработка ошибок

Ошибки работы библиотеки приводят к выбросу исключений `std::runtime_error`. Приложение перехватывает исключения и выводит информацию об ошибке в консоль.
